## Rejection vocabulary

Words the founder uses when something fails, in rough order of severity: **"AI slop"**, **"looks AI-generated"**, **"basic"**, **"not T1"**, **"not premium enough"**, **"a bit plain"**, **"boxy"**. The engine maps them: slop/AI-generated → forbidden-list and type violations; basic/not T1 → structure too thin, hero generic, headings oversized; not premium enough → type too light, spacing too empty, panels missing; plain → sector wants richer exceptions; boxy → imagery proportions.
