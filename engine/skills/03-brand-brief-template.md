# 03 · Art-direction brief (template)

Written by the Brand wizard from Stage 1–2 answers before any code exists. The build agent reads it as law. Every field is filled; "TBD" is not permitted. The owner sees the brief in plain English alongside the three directions.

```
BRIEF · <site name> · v<n> · <date>

1. Positioning
   One sentence: what it is, for whom, what proves it.
   Sector: <A–F> (01 playbook applies; exceptions granted: <list or none>)
   Must look nothing like: <URL(s)> (strict sameness gate)

2. Locked elements (never changed by the engine)
   Logo: locked | may redraw      Wordmark spelling: "<exact>"
   Colours that must appear: <hex list>   Colours that must never appear: <list>
   Words that must never appear (site): <list>   (page titles): <list>
   Other "never do": <owner's lines, verbatim>

3. Palette
   Paper: <hex>   Ink: <hex>   Panel: <hex>   Signature: <hex>   Rule: ink @ <12–18>%
   Light/dark: <light|dark>, because <sector reason>
   Derived from: <logo | sector default | owner must>

4. Type
   Headings: <family>, weights <>, sizes H1 <40–64px> / H2 / H3, sentence case
   Body: <family>, <15–17px>, line-height <1.5–1.6>, measure <60–75ch>
   Labels: <family>, 8–9px tracked uppercase
   Figures: tabular. Serif granted: <no | yes, weight ≥500, where>

5. Shape and rhythm
   Radius: 0 (cards, panels, images) / <0–4px> (inputs, buttons)
   Separators: hairline rules. Shadows: none / <granted exception>
   Grid: 12/4 columns, 24/16px gutters, max-width <1200–1360px>
   Section padding: <64–96px> desktop / 48px mobile
   Density: <low | medium | high> per sector

6. Imagery
   Mode: photography | photographic renders | placeholders now, shoot later
   Product rule: <proportions, angle, lighting, signature element e.g. cap colour>
   Never: <drawn illustration | AI people | stock | 3D blobs>
   Hero media: <image | video | product render>

7. Voice
   Sounds like: <three words>     Never sounds like: <three words>
   Byline: <team name | person>
   Language rules: <sector language, e.g. laboratory framing; naming constraints>

8. Page architecture (homepage)
   Hero: <headline type, proof line, primary action, media>
   Sections in order: <e.g. category bar → featured products → trust strip → how it works → certificates → FAQ → footer>
   Patterns forbidden: three-icon cards, centred gradient hero, pill CTAs (unless granted)

9. Conversion rules
   Add-to-basket from hero: <yes | no>   Price in hero: <yes | no>
   Clicks to checkout: <target ≤ 3>   Chat button: <WhatsApp number | none>

10. Direction chosen
   <Direction name> of three, chosen <date> by <owner>. The other two are discarded.
```

## Notes for the writer

- Derive, don't invent. Every value traces to an answer, a sector default, or the logo.
- If the owner's references conflict with the sector (admires a dark site in a light sector), the brief notes it and the three directions include one that honours the reference within the rules, so the choice is made by seeing.
- The brief is versioned. A change to any locked element is a new version and requires the owner's explicit confirmation.
